Basic HTML/JS tool for scoring candidate American cities that I'm considering relocating to. Broken down into
several dimensions -- cost of living, access to art, etc -- with respective weights that feed into each city's 
score. DataTables library provides sortability and improved aesthetic (compared to raw HTML/CSS at least).

Functionality self-explanatory. Default scores for each city's category provided by Claude responses from
thoughtful, brief prompts (March 2025, v3.7 Sonnet).
